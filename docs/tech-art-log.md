# 技术美术实验日志（Tech Art Log）

> **这是本项目的主要目的的落点**（见 `GDD.md` §0）：dummy-bird 的载体是小游戏，主要产出是**技美能力**。
> 本文件记录每一次技美实验：**想验证什么 → 怎么做的 → 结果 → 学到什么 → 能不能复用**。
> 与 devlog 的分工：devlog 记"那天做了什么"，本文件按**技法主题**沉淀可复用的知识（不按日期）。
> 创建：2026-10-11

---

## 使用约定

1. **每个技法一节**，不按日期排；同一技法有新发现就更新那一节（保留版本/日期标注）。
2. 每节必须有 **「学到什么」** 与 **「可否复用」** 两栏——这是本文件存在的理由；只记"做了什么"等于没记。
3. 实验载体建议用**独立实验场景**（如 `DEV/tech_art/xxx.tscn`），不污染主线（待决策 #13）。
4. 失败的实验也记——**失败的技法边界比成功的更值钱**（"为什么这条路不通"）。
5. 技法若验证可用，在「可否复用」栏写下**怎么搬到下个项目**（要带哪些文件、有哪些前提）。

## 待研究清单（想到就往上加，不必排序）

> 这些是 dummy-bird 这个载体天然适合练的技美方向。按兴趣挑，不必全做。

| # | 方向 | 为什么适合这个项目 |
|---|---|---|
| T1 | **像素完美的缩放与采样** | 已经在做（Nearest + 整数倍缩放），但"为什么这样才不糊"值得亲手验证一遍 |
| T2 | **调色板量化 / 色阶压缩** | 像素风的核心限制；可做一个"把任意图压到 N 色"的 shader 练手 |
| T3 | **抖动（Dithering）** | 与 T2 配套；有序抖动/误差扩散的实现与观感差异 |
| T4 | **屏幕空间特效** | 命中闪白、暂停压暗/去色、速度线——都是全屏 shader，投入小见效快 |
| T5 | **2D 光照与法线** | Godot 的 `CanvasModulate` + `Light2D` + 法线贴图；像素风下怎么用才不像"贴图发光" |
| T6 | **粒子与残影** | 拍翅气流、撞击碎屑；`GPUParticles2D` vs 手写残影的性能与手感对比 |
| T7 | **视差滚动与景深暗示** | 分层滚动 + 雾化/缩放，用极少素材营造纵深 |
| T8 | **顶点/UV 动画** | 让精灵"呼吸"、水面波动——不重画图也能动起来 |
| T9 | **后处理链与性能预算** | 多个全屏 shader 叠加的开销；移动端与 Web 端的差异（Web 端尤其受限） |
| T10 | **调色/时间控制** | 命中时的时间缩放（hit-stop）、失败时的慢动作——手感类技美 |
